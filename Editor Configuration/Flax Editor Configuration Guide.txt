Flax Language Guide. (c) 2026 The Flax Language Project.

The following file details the required information for creating
your own language modules and scripts for your preferred editor. If
you do so, they can be added to the Flax GitHub Repository.

This guide will be updated when required to include additional
features or language changes.

For ease of readability, all the following sections within your editor's
configuration should be highlighted in separate colours.


Comments
-------------------------------------------------------------
Comments can be whole line or post instruction; there is no 
ability for block-style comments.  Comments start with ';’.

;This is a line comment.

lda 10 ;This is a inline comment.


Execution and Compiling:
-------------------------------------------------------------

runflax fileName.flax -i.	;Runs file in terminal interactive mode

runflax fileName.flax		;Runs file in normal terminal blocking mode

runflax fileName.flax -c	;Only compiles the file without execution

runflax fileName.flax -e	;Encrypts the flax file saving it with a .eflax entension

runflax				;Shows all available switches and help


Labels:
-------------------------------------------------------------
Labels are a single word suffixed with a ":" on a line by
themselves, though they can be followed by a comment.

label:

label: ;Inline comment.


Number:
-------------------------------------------------------------
Numbers can be bytes, integers, or floating point.  The '&'
symbol should be included with the number as it's used
to specify memory block size on a variable definition.

10

-10

10.1

&10
